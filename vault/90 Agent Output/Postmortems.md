# Postmortems

Each time the second brain fails and someone catches it, the failure gets an entry here: a stale backup, a wrong answer, a search that missed something it should have found. The entry isn't finished until a fix is in place. A failure that is only described will happen again, so every entry needs an actual fix. The idea comes from [NaluKicks-808/second-brain-kit](https://github.com/NaluKicks-808/second-brain-kit).

Each entry answers four questions:

## 1. Short name of the failure (YYYY-MM-DD)

- **What happened:**
- **Why:**
- **Fix:** the script, setting or rule that is now in place.
- **How we'd know:** the check that would catch it next time.
